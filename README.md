# 👨🏻 About Me  
I’m a recent graduate of the Master of Data Science program at the University of British Columbia (UBC), passionate about applying machine learning to solve real-world problems. With a strong foundation in data engineering, analytics, and model development, I’m eager to keep learning, grow professionally, and contribute meaningfully to society.

Collaboration is something I value deeply. I enjoy working with others to tackle challenges, build clean and reproducible workflows, and continuously learn from those around me. My interests lie in building practical learning pipelines that make a meaningful impact.

Outside of work, I recharge by hiking and playing badminton with friends. Whether it’s scaling a mountain or smashing a shuttlecock, I believe balance and movement help keep the mind sharp and creative.

# 📂 Featured Projects  

### [Sniffing for Phishing](https://github.com/JiaQuanLim/phishsense-v2)  
End-to-end ML pipeline for phishing email detection.  
- Extracted structured features from raw `.eml` files  
- Built a **stacked XGBoost ensemble**, improving F1-score by **40% over baseline**  
- Packaged into a **containerized REST API**  

---

### [Flight Delay Prediction](https://github.com/JiaQuanLim/Flight-Delay-Prediction)  
Machine learning model to predict flight arrival delays.  
- Applied **ensemble methods** (Voting, Stacking)  
- Tackled data imbalance with **oversampling/undersampling**  
- Compared **random vs stratified splits** for generalization  

---

### [Gapminder Shiny Dashboard](https://github.com/JiaQuanLim/Gapminder-Shiny)  
Interactive R Shiny dashboard for exploring global development trends.  
- Filter by country, year, and metrics (GDP, life expectancy, population)  
- Built with **R, Shiny, ggplot2**
